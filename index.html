Strava Activity Tracker MCP

A powerful Model Context Protocol server that connects your Strava training data to Claude. Turn AI into your personal running coach, performance analyst, and training partner.

View on GitHub See Demo
✨

Features

🏃‍♂️ Personal Coach

Generate custom 5k, 10k, Half, or Marathon plans based on your actual fitness levels with heart rate zones.

📊 Deep Analysis

Per-kilometer breakdown of pace, heart rate efficiency, and cardiac drift for every workout.

🏆 Personal Records

Instant access to your all-time best efforts (1k, 5k, 10k) and lifetime running/cycling totals.

🧠 Smart Filtering

Automatically finds the right activity type (Run, Ride, Walk) even if you've done other workouts since.

Quick Start & Setup View README docs ↗

1

Prerequisites

Ensure you have Python 3.11+ and the fast Python package manager uv installed globally.

You also need Strava API Credentials. Click here to see detail explaination.

2

Clone & Sync

Download the repository and install dependencies using uv. Do not use standard pip install.

git clone https://github.com/RaHuL-J31/activity-tracker-mcp.git cd activity-tracker-mcp uv sync
3

Configuration (.env)

Copy .env.example to .env and fill in your Client ID and Secret. Leave the token fields empty.

STRAVA_CLIENT_ID=12345 STRAVA_CLIENT_SECRET=abc123yoursecret STRAVA_ACCESS_TOKEN='' STRAVA_REFRESH_TOKEN='' STRAVA_TOKEN_EXPIRES_AT=0
Note: Even if the Strava dashboard shows you an "Access Token," it lacks the necessary permissions to read activity data. The script in the next step handles this.
4

Authentication

Run the helper script to authorize the app. A browser window will open.

uv run scripts/get_token.py

Click Authorize. You will be redirected to a localhost URL. Copy the complete URL from the browser and paste it back into your terminal. Your secure tokens are now saved!

🛠️

Testing & Verification

Always run commands from the project root directory to ensure paths resolve correctly.

Command Purpose
uv run scripts/health.py Basic check for .env setup and basic API connectivity.
uv run scripts/mcp-integration-test.py Full integration test of all 5 MCP tools with your real Strava data.
uv run scripts/get_token.py Run this if you face "Unauthorized" errors to refresh tokens (One-time process). This is only if you get an error in the above commands.
🤖

Claude Desktop Integration

To connect this server to Claude, add the following to your claude_desktop_config.json.

Windows

"mcpServers": { "strava": { "command": "uv", "args": [ "run", "--directory", "C:\\Path\\To\\activity-tracker-mcp", "src\\main.py" ] } }

macOS / Linux

"mcpServers": { "strava": { "command": "uv", "args": [ "run", "--directory", "/path/to/activity-tracker-mcp", "src/main.py" ] } }

Available Tools & Queries

Tool Name Description Example Question for Claude
check_strava_connection Verifies if Claude can securely talk to Strava. "Is my Strava connection working?"
get_recent_activities Lists your latest recorded workouts. "Show me my last 5 activities."
analyze_workout Detailed per-km split & HR analysis. "Analyze my last run and check for heart rate drift."
get_personal_records Shows lifetime totals and Metric PRs. "What are my PRs for 5k and 10k?"
generate_training_plan AI Coach creates a week-by-week plan with zones. "I want to run a sub-50min 10k in 10 weeks. Build me a plan."
Safety First: The Coach tool will deny unrealistic goals (e.g., Marathon in 1 week) to prevent injury. Always prioritize metric units for precision.

Detailed Strava API Setup Guide

Follow these precise steps to get your credentials if you are setting this up for the first time:

  1. Login to Strava: Visit the Strava API Settings.
  2. Create Application: You will be taken to the "My API Application" page.
    • Application Name: Give it any name (e.g., "My Activity Tracker"). Note: Do not use the word "Strava" in the name.
    • Category: Select Performance Analysis.
    • Club: Select None.
    • Website: Use www.website.com for now.
    • Application Description: You can leave this empty.
    • Authorization Callback Domain: Set this to localhost (Crucial step!).
  3. Upload Logo: Strava requires a logo. You can find a logo.png in the repository, or upload any small image.
  4. Get Credentials: Click Create. You will now see your Client ID and Client Secret.
  5. Update .env: Copy these two values into your .env file. Ignore the "Access Token" on the website.
